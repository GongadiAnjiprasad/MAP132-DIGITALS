# MAP132 DIGITALS — Festival Wishes

This is a small, self-contained seasonal module mounted by the existing public homepage.

## Visitor experience

- Uses the India calendar (Asia/Kolkata), not the visitor device timezone.
- During the ten days before a configured festival, shows only subtle, non-blocking background particles.
- On the festival date, shows one MAP132 DIGITALS greeting banner with the original logo, brand name, and festival wish.
- Visitors can skip or close the greeting. It does not block navigation or autoplay sound.
- After the festival date, the greeting automatically disappears and the normal website returns.

## Free automatic image generation

- Cloudflare Workers AI uses the @cf/black-forest-labs/flux-1-schnell model through a server-side binding.
- A scheduled Worker generates one festival background image on the festival date and caches it in the existing MAP132_KV namespace.
- The original MAP132 logo and all greeting text are layered by the website, not generated by the model, so brand spelling remains accurate.
- The site has a CSS-only fallback if the AI binding, free quota, or generation service is unavailable.
- No paid API, browser-side API key, or per-visitor generation is used.

## Calendar maintenance

Edit FESTIVAL_CALENDAR in festivalCalendar.ts. Festival dates are curated configuration, not fetched from a third-party calendar. Verify lunar-calendar dates for each year before adding them.

## Safe release

Run npm test, npm run test:e2e, and npm run build. Keep the module and Worker integration isolated; do not change the homepage shell or editor workspace for seasonal styling changes.
