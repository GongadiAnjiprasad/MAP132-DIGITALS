# Ramayanam Trailer Studio — isolated preview

This feature adds a private Trailer Studio tab to the MAP132 Editor Workspace.

- Scene cue sheet: nine edit sections covering the planned 90-second Varsham × Ramayanam fan trailer.
- Dialogue library: original Telugu narration/dialogue drafts and Bhagavad Gita 4.7 / 4.8 excerpts with copy controls.
- Sound effects: reuses the existing eligible CC0 / CC-BY sound search, preview and download endpoints.
- Music: links to Mixkit Music and YouTube Audio Library; locally owned/licensed BGM and recorded voiceovers can be imported through the existing private My Drive resource library.
- Existing Cinematic Sounds, Cinematic Fonts and My Drive tabs remain separate and unchanged.

No production deployment has been performed. This feature remains on its isolated branch pending build, unit, desktop/mobile browser checks and user review.
